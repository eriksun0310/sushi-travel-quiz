# 壽司旅人測驗

壽司日檢的導流測驗：16 題四軸計分，算出 16 型「壽司旅人」，
結果頁把使用者導向 App 裡對應的單字主題包。

## 跑起來

```bash
pnpm install
cp .env.example .env.local   # 填 NEXT_PUBLIC_APP_STORE_URL
pnpm dev
```

## 路由

| 路徑 | 說明 |
| --- | --- |
| `/` | 首頁。帶 `?from=<code>` 時會顯示邀請人的型別 |
| `/quiz` | 16 題作答，純 client state，答完 push 到結果頁 |
| `/r/[code]` | 結果頁。16 個代碼各自靜態產生，帶 `?from=` 時顯示兩人組合 |
| `/r/[code]/opengraph-image` | 每一型的 OG 圖（next/og，1200×630） |
| `/types` | 16 型一覽 |

## 代碼怎麼讀

四碼，順序同 `src/content/axes.ts` 的 `AXES`：

| 位置 | 軸 | `1` | `0` |
| --- | --- | --- | --- |
| 0 | 規劃 | 表格派 計 | 隨便走派 隨 |
| 1 | 消費 | 克制 省 | 失手 爆 |
| 2 | 社交 | 敢開口 問 | 比手畫腳 比 |
| 3 | 動機 | 打卡收集 集 | 體驗沉浸 沉 |

`'0000'` = 隨爆比沉 = 大トロ。

## 文案放哪

全部在 `src/content/`，沒有 CMS、沒有後端：

- `questions.ts` — 16 題與每個選項的權重（+2 / +1 / -1 / -2）
- `types.ts` — 16 型的型名、標籤、吐槽、橋接句、對應主題包
- `poles.ts` — 八個極端各一份維度文案（金句 / 長文 / 口頭禪），16 型由此組合
- `pairing.ts` — 旅伴配對的說明句（目前是公版，待手寫）
- `topics.ts` — 對應 App 既有主題包的字數
- `levels.ts` — 沿用 App 的 `levelColors`

## 邀請機制

沒有後端。`/?from=<code>` 把邀請人的型別帶在網址裡，
對方測完後在自己的結果頁看到兩人組合，再用 Web Share / 剪貼簿把連結傳回去。
