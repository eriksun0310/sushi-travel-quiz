# 壽司旅人

日本旅遊人格測驗：16 題四軸計分，算出 16 種「壽司旅人」。
結果頁最後接上壽司日檢的 26 種壽司收集牆 —— 橋不是內容，是壽司本身。

## 跑起來

```bash
pnpm install
cp .env.example .env.local
pnpm dev
```

## 路由

| 路徑 | 說明 |
| --- | --- |
| `/` | 首頁。帶 `?from=<code>` 時顯示邀請人的型別 |
| `/quiz` | 從 27 題題庫每軸抽 4 題，純 client state |
| `/r/[code]` | 結果頁。16 個代碼各自靜態產生，帶 `?from=` 時顯示兩人組合 |
| `/r/[code]/opengraph-image` | 每一型的 OG 圖，連結預覽用（next/og，1200×630） |
| `/api/card/[code]` | 每一型的社群分享卡，直式海報（next/og，1080×1350） |
| `/types` | 16 型一覽 |
| `/dev` | 開發用跳板，一頁點到任何一型的結果頁 / 分享卡 / OG 圖（noindex，站上沒有連結指過來） |

## 代碼怎麼讀

四碼，順序同 `src/content/axes.ts` 的 `AXES`：

| 位置 | 軸 | `1` | `0` |
| --- | --- | --- | --- |
| 0 | 規劃 | 表格派 | 隨便走派 |
| 1 | 消費 | 克制 | 失手 |
| 2 | 社交 | 敢開口 | 比手畫腳 |
| 3 | 動機 | 打卡收集 | 體驗沉浸 |

`'0000'` = 隨便走 × 失手 × 比手畫腳 × 沉浸 = 大腹（富）。

型名是人格名，不一定等於 App 裡那盤壽司的名字：
`catalog.ts` 用的是 App 的原名（大トロ），`types.ts` 用的是這個測驗的型名（大腹（富））。

## 壽司怎麼配

**敢花的拿高級壽司。** 消費軸決定貴賤，動機軸決定是「少而精」還是「多而雜」：

| | 沉浸（少而精） | 打卡（多而雜） |
| --- | --- | --- |
| 敢花 | N1 頂級 | N2 中高 |
| 省 | N5 樸素 | N4 大眾 |

N 等級**不會出現在畫面上**，它只決定 `LEVEL_COLORS` 的卡片配色 —— 使用者看到深紫黑的卡就知道自己抽到高級的。
N3 那一排測驗永遠抽不到，只有 App 的圖鑑裡有。

## 出題規則

- 一題只量一個軸，選項是**動作**不是心情，四個選項沒有正確答案
- 選項人格固定：**A** 誇張的準備過頭 → **B** 正常的正端 → **C** 負端但有藉口 → **D** 擺爛但理直氣壯
- **笑點永遠在 D。** 寫新題先寫 D
- **零日文。** 要提到日文就用描述的：「店員用日文問你要幾個」
- 各軸的題材範圍：規劃＝時間與順序、消費＝掏錢、社交＝跟陌生人發生關係、動機＝停留多久

題庫在 `src/content/questions.ts`，27 題（規劃 6 / 消費 10 / 社交 6 / 動機 5）。
消費軸池子最深，所以重測時消費題的差異最大 —— 那也是最好笑最好傳的一軸。

## 文案放哪

全部在 `src/content/`，沒有 CMS、沒有後端：

- `questions.ts` — 題庫與每個選項的權重
- `types.ts` — 16 型的型名、標籤、吐槽
- `dimensions.ts` — 四張維度卡的本文，**每型各一份，16 × 4 = 64 段全不重複**。
  寫法是「這個軸 × 這型的其他特質」：同樣是失手，配沉浸是被氣氛推的，配打卡是被速度推的
- `poles.ts` — 八個極端各一份：維度卡的金句 + 四句口頭禪。
  口頭禪挑哪一句由「其餘三軸」決定，所以同極端的不同型別不會拿到同一句
- `pairing.ts` — 旅伴配對的說明句。配對是對稱的，16 型組成 8 對合拍 + 8 對要小心，每對兩邊看到同一句
- `catalog.ts` — App 的 26 種壽司，收集牆用
- `levels.ts` — 沿用 App 的 `levelColors`
- `store.ts` — 壽司日檢的 App Store / Google Play 連結

分享卡用的壽司圖在 `public/sushi-card/`（PNG，已裁掉透明留白）——
satori 不吃 webp，所以跟站上用的 `public/sushi/` 分開放。

## 邀請機制

沒有後端。`/?from=<code>` 把邀請人的型別帶在網址裡，
對方測完後在自己的結果頁看到兩人組合，再用 Web Share / 剪貼簿把連結傳回去。

## 結果頁哪些東西是每型獨有的

| 區塊 | 份數 |
| --- | --- |
| 壽司圖 / 型名 / 標籤 / 一句話 / 吐槽段 | 各 16，全不同 |
| 四張維度卡的本文 | 64，全不同 |
| 口頭禪 | 32 句，兩型平均重疊 0.27 句 |
| 旅伴說明句 | 合拍 8 + 要小心 8（配對本身是對稱的，每對兩邊同句） |
| 維度卡的金句 | 8，八個極端共用 —— 刻意的，它是標籤不是內容 |
| 卡片配色 | 5 級，由消費軸與動機軸決定貴賤 |

改文案之後可以跑一次全掃描確認沒有意外重複。
